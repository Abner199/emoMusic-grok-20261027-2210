# 当AI遇见旋律：从表情感知到智能音乐推荐

品牌 **心弦 EmoTune**。

> **当前快照** 2026-10-28 09:51 · 标签 `snapshot-20261028-0951` · 仓库 [emoMusic-grok-20261027-2210](https://github.com/Abner199/emoMusic-grok-20261027-2210)  
> 换电脑逐步启动见 [SETUP.md](SETUP.md)。固定版本、上一版 224 首快照与如何继续开发见 [VERSION.md](VERSION.md)。  
> 静态介绍页：https://emomusic-gt-20261028.surge.sh

本机人脸情绪识别歌曲推荐。用摄像头、照片、本地视频或屏幕画面识别七类基本情绪（喜、怒、哀、惧、惊、厌、中性），再按情绪播放匹配的华语校园热歌。

## 功能

- 四种输入：实时摄像头（可切换多个设备）、本地照片（JPG / PNG / WEBP）、本地视频、屏幕分享；上传页可点选已命名的典型表情，也可从 `static/demo` 直接上传
- 七类情绪：喜悦、愤怒、悲伤、恐惧、惊讶、厌恶、平静
- 本地识别：YuNet 检测 + MobileFaceNet FER（Ekman 七类，RAF-DB 公开评测 **88.27%**），单人精检再融合 HSEmotion EfficientNet-B0（AffectNet 野外）并做翻转/微转 TTA 与多帧平均。可切「多人远场」同时检测多张脸和远景小脸，歌曲按人数最多的情绪来
- 人脸窗：可弹出独立窗口看人脸框和情绪标签，同样可切换检测方式和摄像头
- 旋律曲调情绪：Thayer 效价-唤醒 + Krumhansl–Kessler 调式 + Juslin 声学线索，本机抽取 BPM、大小调与能量
- 推荐策略可选：同频、修复、先同频再修复，以及对比、回暖、降唤醒、升效价、强化、平衡；每种都有理论说明
- 算法、理论与使用说明在独立页面 `/guide`，主页不堆长文；顶部「说明」可打开
- 本地曲库：280 首有人声试听，每类 40 首，按情绪分好；缺文件时按规则生成旋律兜底，断网也能连播
- 歌曲以华语校园热门为主，少量英文；切换情绪时曲风反差尽量明显
- 识别成功后自动连播，当前列表播完自动切下一首；本地曲可下载
- 实时捕捉（可开关）：打开后持续识别表情并推荐歌曲；摄像头画面实时画出人脸框，并动态显示表情文字
- 识别此刻：截取当前画面识别并播放歌曲，同时自动关闭实时捕捉
- 惊讶、恐惧、愤怒、厌恶等很难长时间保持的表情会锁定歌单，脸松开也不会立刻换歌；做出另一种明显表情并确认后才切换
- 情绪标签变化时可语音播报，顶部开关可关
- 播放时显示实时歌词、封面、波形和频率，均可单独关闭
- 当前情绪图标旁对照显示用于判断的人脸截图；足迹与历史同样保留对照，并列出当时播放过的歌曲
- 每首歌名旁标记这首歌自己的情绪标签（喜 / 怒 / 哀 / 惧 / 惊 / 厌 / 中）；足迹和历史里同样标注，方便核对歌曲与表情是否对得上
- 情绪足迹全部保存，不截断。每条含表情图标、真实人脸截图和播过的歌；相同情绪再次识别时尽量换没听过的歌。点选足迹可回放当时的歌
- 识别历史写在项目的 `data/history.json` 与 `static/history/*.jpg`，换一台电脑复制整个文件夹部署也会保留
- 六种主题：夜金、宣纸、墨青、朱砂、青瓷、月白，选择会记在本机
- 界面为简体中文，少量必要英文（品牌 EmoTune、英文歌名、文件格式、本机地址）
- 默认使用在线曲库：并行检索苹果音乐、网易云、咪咕、酷狗、QQ 音乐、酷我；可手动关闭「在线曲库」只用本地。在线歌曲长时间播放失败会提示并自动切到本地

## 技术栈

| 模块 | 方案 |
| --- | --- |
| Web | Flask（线程模式）+ HTML / CSS / 原生 JavaScript |
| 人脸检测 | OpenCV YuNet ONNX |
| 表情识别 | OpenCV Zoo MobileFaceNet FER（RAF-DB **88.27%**）× HSEmotion B0；单人精检 TTA + 多帧融合 |
| 曲调情绪 | Thayer 二维模型 + Krumhansl–Kessler 调式 + Juslin 声学线索 |
| 推荐 | 九种可选策略（默认同频 ISO + 余弦）；完整理论见 `/guide` |
| 本地音频 | iTunes 香港/台湾/美国店 30 秒有人声试听缓存（m4a） |
| 在线音乐 | 苹果音乐、网易云、咪咕、酷狗、QQ 音乐、酷我（默认开启）；经本机 `/api/stream` 代理试听 |
| 歌词 | 本机按曲目准备的 0–30 秒逐行歌词 |
| 历史 | 全局列表全部保留：表情图标、人脸截图、播过的歌；随项目目录一起复制 |

识别在 CPU 上通常几十到一百毫秒；默认走在线热歌，接口总耗时目标不超过 3 秒。

## 使用

1. 检测方式默认 **单人精检**（只认近景主脸）。课堂合影或远镜头再切 **多人远场**
2. 点 **开启摄像头**，把面部落在椭圆里；可用下拉框切换多个摄像头。画面会实时标出人脸框并显示表情文字
3. 打开 **实时捕捉** 可持续识别并推荐歌曲；点 **识别此刻** 会截图识别并自动关闭实时捕捉
4. 也可切到 **照片** 拖入正面人脸图或点选示例，**视频** 打开本地 MP4 / WEBM，**屏幕** 分享窗口或整屏
5. 右侧对照显示人脸截图、情绪大字、七维分数；下方列出 24 首推荐并自动播放
6. 歌曲区可选推荐方式（同频 / 修复 / 先同频再修复等）；顶部「说明」打开算法、理论与用法
7. 顶部可开关：在线曲库、语音提示、歌词、封面、波形；可切换夜金 / 宣纸 / 墨青 / 朱砂 / 青瓷 / 月白
8. **情绪足迹** 会全部留下人脸、情绪图标和当时听过的歌；点选可回放。相同情绪再次识别时会尽量换没听过的歌。**历史** 抽屉里也能回看全部记录

空格键：在页面空白处可触发一次识别。

惊讶、恐惧这类表情很难一直摆着。打开实时捕捉后会锁定当前歌单，脸松开或变回平静时不会立刻换歌；做出另一种明显表情并保持一下才会切。点「识别此刻」会改用这一帧截图，并关闭实时捕捉。

## 准确率说明

表情模型来自 [OpenCV Zoo Facial Expression Recognition](https://github.com/opencv/opencv_zoo/tree/main/models/facial_expression_recognition)，MobileFaceNet 在 RAF-DB 上报告准确率 88.27%。单人精检再叠加 [HSEmotion EfficientNet-B0](https://github.com/HSE-asavchenko/face-emotion-recognition)（AffectNet 野外人脸）、翻转/微转 TTA 和多帧概率平均，本机对示例图做压缩/明暗/微转稳健测试目标 **≥90%**。实际效果依赖：

- 正面、完整五官、没有墨镜/口罩遮挡
- 光线尽量均匀；过暗时会做轻度亮度校正
- 近景、单人时使用默认「单人精检」；远景或多人才切「多人远场」
- 摄像头、视频、屏幕模式下连拍 4 帧做概率平均，截图用更高 JPEG 质量

## 在线 API

默认打开顶部「在线曲库」，识别后优先播放在线热歌。服务端并行请求：

- 苹果音乐 Search（香港/台湾/美国店，含 30 秒试听）
- 网易云公开搜索与试听地址
- 咪咕、酷狗、QQ 音乐、酷我公开搜索与试听
- Deezer（部分网络会 403，失败时自动跳过）

试听经本机 `/api/stream` 代理，方便浏览器直接播放。关闭开关即只用本地 40 首/类。在线歌曲连续播不了或超过约 12 秒仍失败时，会提示并自动切到本地曲库。在线结果会过滤纯音乐、伴奏、翻唱与库存配乐。

## 常见问题

**提示未检测到人脸**  
换正面照片，提高亮度，让整张脸进入取景框。远景或合影请切到「多人远场」。

**摄像头黑屏**  
用 `http://127.0.0.1:5000` 访问，并在浏览器中允许摄像头权限。

**在线歌曲不能完整播放**  
这是源站 30 秒试听限制。本地曲库缓存的也是官方 30 秒人声试听，可播放和下载。

**惊讶表情一放松就换歌**  
实时捕捉会锁定短暂表情的歌单。脸松开后仍继续播；做出另一种明显表情才会切。点「识别此刻」会截图识别，并关闭实时捕捉。

**换电脑后历史没了**  
请复制整个项目文件夹，不要只拷 `app.py`。历史在 `data/history.json` 和 `static/history/`。情绪足迹会全部保存，不会自动丢掉旧记录。

**相同情绪又播到同一首歌**  
新识别会优先跳过这个情绪已经听过的歌；点足迹回放当时的歌不受这个限制。全部听过之后会从最早听过的歌再轮一圈。

**首次启动较慢**  
正在下载模型并缓存有人声歌曲试听，以后启动会跳过这一步。
