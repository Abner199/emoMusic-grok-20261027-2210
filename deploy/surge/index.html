在新电脑上启动

  1. 安装 Python 3.10 或 3.11（勾选 Add to PATH），以及 Chrome / Edge。
  2. git clone https://github.com/Abner199/emoMusic-grok-20261027-2210.git
  3. cd emoMusic-grok-20261027-2210 然后 git checkout snapshot-20261028-0951
  4. python -m pip install -r requirements.txt
  5. python app.py 或双击 run.bat
  6. 浏览器打开 http://127.0.0.1:5000。摄像头必须用这个地址。

逐步说明、端口占用、足迹怎么拷，见仓库里的 SETUP.md 与 VERSION.md。

本版要点

  • 单人精检：YuNet + MobileFaceNet TTA × HSEmotion，本机稳健测试目标 ≥90%
  • 可切多人远场；四种输入：照片 / 摄像头 / 视频 / 屏幕
  • 本地 280 首按情绪分类的人声试听，外加在线曲库
  • 九种推荐策略，说明页 /guide
  • 情绪足迹全部保存在本机，不进 GitHub
