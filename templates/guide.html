使用说明

主页操作一遍就会

  1. 用 Chrome 或 Edge 打开 http://127.0.0.1:5000（本机占用时用启动时提示的端口）。摄像头必须走本机地址。
  2. 四种输入都可做人脸情绪检测：摄像头（可切换设备）、照片、本地视频、屏幕分享。视频和屏幕只截当前帧，不把整段文件上传。
  3. 检测方式默认为「单人精检」：只取近景里最大最稳的一张脸，阈值更高，适合自拍和对镜。课堂合影或远镜头再切「多人远场」。
  4. 点「开启摄像头」，把面部落在椭圆里。可用下拉框切换多个摄像头。画面会框出人脸并标出情绪。
  5. 打开「实时捕捉」可持续识别并按当前推荐方式连播。日常以平静、喜悦、悲伤为主，这三类会稳住再换歌。惊讶、恐惧、愤怒、厌恶是短高潮：认到后锁反差歌单，脸松开也不会立刻换歌；持续平静几秒后会切到平静歌单。人脸框、左侧「此刻情绪」、播放器情绪、音乐可视化和语音提示共用同一套七类标签。高潮情绪很快语音提示，日常三类稳住约 3 秒才说；点「识别此刻」或上传立刻说一次。
  6. 点「识别此刻」会截取当前画面识别并播放，同时关掉实时捕捉。
  7. 也可切到「照片」，拖入 JPG / PNG / WEBP，或点选已命名的示例表情；「视频」选本地 MP4 / WEBM；「屏幕」分享窗口或整屏。
  8. 点「弹出人脸窗」可把人脸画面放到独立窗口，方便放到第二块屏幕。弹窗独占摄像头，也可切换设备和检测方式。
  9. 「多人远场」下多人同时入镜时，每张脸各自识别；歌曲按人数最多的情绪执行，票数相同再比面积和置信度。
  10. 顶部「设置」里可选推荐方式，默认同频：同频、修复、先同频再修复、对比、回暖、降唤醒、升效价、强化、平衡。换方式会立刻重排歌单。检测方式、铺满窗口、铺满画面、比率、主题颜色也在设置里，默认收起。
  11. 设置里可开关：在线热歌、语音提示、歌词、封面、声纹。实时捕捉时人脸框和此刻情绪跟脸走：日常三类约半秒连续一致才切换此刻；高潮四类更快确认并锁反差歌。语音：平静喜悦悲伤稳住约 3 秒说一次，惊讶恐惧愤怒厌恶认到后很快说。点「识别此刻」或上传照片会立刻说一次。此刻情绪旁显示融合后 p(k) 概率条和 Russell 效价-唤醒环面。声纹打开时，播放器画出振动 x(t)、快慢 BPM、频率 |X(f)|、音调 f₀ 和 Thayer 效价-唤醒平面。图的颜色跟人脸此刻同一套七类标签；V·A 是数值。推荐默认同频。关掉「在线热歌」只用本地 532 首；在线长时间播不了会提示并自动切本地。
  12. 情绪足迹全部保存。点选可回放当时的歌，回放不计入新的已播。相同情绪再次识别会尽量换没听过的歌。

人脸情绪识别

YuNet + MobileFaceNet FER × HSEmotion

经典：Ekman 七类基本情绪（1992）；OpenCV Zoo 人脸表情识别；公开评测 RAF-DB 88.27%；HSEmotion EfficientNet-B0（AffectNet 野外）

  1. 两种可切换模式。默认单人精检：检测阈值更高，只保留最大最稳的一张近景脸，不做远景放大和 Haar 补检。检出后在脸附近再检一次，把五点对齐到 112×112。
  2. 单人精检分类走高精度路径：MobileFaceNet FER 做原图、水平翻转和 ±7° 微转的 TTA；再跑 HSEmotion EfficientNet-B0（AffectNet 野外人脸，多尺度裁剪 + 翻转）。两模型判断一致时加权平均；不一致时更信野外模型，避免实验室模型在摄像头上过自信。多帧截图按七类概率平均，不取单帧最高分。
  3. 多人远场：YuNet 在较高分辨率上检出画面里的每一张脸，包括远景小脸（输入约 1280，阈值放宽后再用高阈值对齐近景）。找不到脸时会放大再检，再不行走 Haar。
  4. 摄像头实时框走轻量路径：YuNet 出框并给出五点（左眼、右眼、鼻尖、左右嘴角），网页按瞳距在眼上方估计眉区；同时用嘴宽/IOD 与嘴角上扬对照 FACS AU12 / AU15 / AU27。没有张口+挑眉时会把惊讶压回平静，没有拉开上扬时会把喜悦压回平静，减少休息脸和说话口型误锁。关键点可切「实拍」把动作单元贴在脸上，「线框」画眉眼鼻口骨架，也可关闭。分类仍是 MobileFaceNet 单次前向，隔帧叠加一次 HSEmotion，再用跨帧指数平滑稳住标签。框和关键点在网页里用 60fps 插值。画面可铺满窗口并调节放大比率。点「识别此刻」仍走完整 TTA 精检。
  5. 每张脸输出七类概率：喜、怒、哀、惧、惊、厌、中性。单人精检按主脸情绪推荐。多人远场按人数最多的情绪执行；并列时取面积更大、再取平均置信度更高的一类。

模型是本机 ONNX，图像不上传。可弹出独立人脸窗查看人脸框和标签。单人精检通常一两百毫秒，摄像头截图用更高 JPEG 质量以保住眉眼细节。

歌曲旋律曲调情绪

Thayer 二维模型 + Krumhansl–Kessler 调式

经典：Thayer 1989 效价-唤醒 · Krumhansl–Kessler 1982 大小调剖面 · Juslin 2001 声学线索

  1. 能量包络自相关网格搜索速度（54–176 BPM，Scheirer / Ellis）。
  2. 12 音级直方图与 Krumhansl–Kessler 大小调剖面求相关，判断大调 / 小调。
  3. 调式决定效价 valence，速度与能量决定唤醒 arousal，再投到七类情绪。
  4. 播放时浏览器 Web Audio 再抽实时振动 x(t)、谱通量节拍、对数频谱 |X(f)|、12 音级色度、基频峰值 f₀（80–500 Hz）和频谱质心 C，叠到歌曲预先算好的 Thayer / KK / Juslin 线索上。整组图按当前人脸情绪换色（喜金、怒赤、哀蓝、惧紫、惊粉、厌青、中性银灰），与人脸框、此刻情绪、播放器共用同一套标签。V·A 卡片只写效价-唤醒数值。

能解码的波形直接抽特征；人声 AAC 试听在未装解码器时，用同一规则分析该情绪的典型旋律骨架，并与 Juslin 对照表印证。全程本机 numpy / scipy。

曲库与在线接口

人声试听，不是纯音乐

  • 本地曲库按七类情绪分好，每类 76 首，共 532 首 30 秒人声试听。播放中文优先，仅特别网红英文作为例外。喜悦以小苹果打头，悲伤以后来打头。人脸框与界面主色：平静天蓝、喜悦亮黄、愤怒正红、悲伤暗灰蓝、恐惧深紫、惊讶鲜橙、厌恶浊绿。缺文件时按规则生成旋律兜底，断网也能连播。
  • 默认走在线接口：先检索苹果音乐、苹果热歌榜、苹果热播、苹果亚洲热歌，不够再补网易云热歌榜、QQ 热歌榜、网易云、咪咕、酷狗、QQ 音乐、酷我、Deezer、Audius；可手动关掉「在线热歌」只用本地。在线长时间播不了会提示并自动切回本地。
  • 在线试听经本机 /api/stream 同源代理，播放器才能画实时振动、快慢、频率和音调。
  • 歌词能联网时用 QQ 官方 LRC，并按 30 秒试听窗口对齐；断网用本机词。可关。

换电脑部署

完整步骤见仓库里的 SETUP.md

  1. 新电脑安装 Miniconda3（或 Anaconda3）以及 Chrome / Edge。Python 用 conda 环境里的 3.12，不要用系统 Python。
  2. 克隆仓库并回到小学 40 分钟成功场：git clone https://github.com/Abner199/emoMusic-grok-20261027-2210.git 后执行 git checkout snapshot-20261028-1525。
  3. 双击 tools\setup-conda.bat，或 conda create -n emotune python=3.12 pip -y 后 conda activate emotune，再 python -m pip install -r requirements.txt。启动：python app.py 或双击 run.bat。
  4. 浏览器打开 http://127.0.0.1:5000。摄像头必须用 127.0.0.1 或 localhost。端口被占用时：set EMOTUNE_PORT=18765 再启动。
  5. 若要带走旧足迹：整夹拷贝，或旧电脑运行 tools\pack-local-data.bat，新电脑把 zip 放到 data\ 再运行 tools\unpack-local-data.bat。data/history.json、data/prefs.json、static/history/ 不进 GitHub。
  6. 核对：python tests/selfcheck.py。详细说明见项目根目录 SETUP.md 与 VERSION.md。
